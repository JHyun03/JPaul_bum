# 🥕 당근 사진 마을 전시회

당근 사진 동호회 회원들이 찍은 사진을 **아늑한 마을 광장을 산책하며** 감상하는 온라인 전시회입니다.
회원은 주민 캐릭터를 골라 입장하고, 광장 액자(이젤)에 자기 사진을 직접 걸 수 있어요.

## 기능
- **주민 캐릭터 선택**: 당근이 · 토순이 · 무무 · 감자도리 · 다람이 · 밤톨이 (6종) + 닉네임
- **마을 산책**: 방향키/WASD로 걷기, 모바일은 화면을 눌러 이동
- **작품 감상**: 액자 앞에서 `Space`/`E`를 누르거나 액자를 클릭하면 크게 보기
- **작품 걸기**: 사진 업로드(JPG·PNG·WEBP·GIF, 최대 10MB) + 제목 + 작품 이야기
- **좋아요 ♥**, **모아보기**(전체 / 내 작품 / 인기순), **내 작품 내리기**
- 안내원 대화창, 30초마다 새 작품 자동 반영

## 실행
```bash
npm install
npm start          # http://localhost:3000
PORT=8080 npm start
```
Node.js 18 이상이 필요합니다.

## 구조
```
server.js              Express 서버 (업로드/조회/좋아요/삭제 API)
public/index.html      화면 (타이틀 → 캐릭터 선택 → 마을)
public/js/characters.js  캐릭터 정의 (SVG 일러스트)
public/js/app.js       마을 이동·전시·업로드 로직
public/css/style.css   스타일
data/photos.json       작품 정보 (자동 생성)
uploads/               업로드된 사진 (자동 생성)
```

## 캐릭터 이미지 바꾸기
기본 캐릭터는 이 프로젝트용으로 새로 그린 오리지널 SVG입니다.
사용 허락을 받은 다른 캐릭터 이미지가 있다면 `public/characters/`에 넣고
`public/js/characters.js`에서 해당 캐릭터에 `image: '/characters/파일명.png'`을 추가하면 SVG 대신 그 이미지가 쓰입니다.

## 참고
- 로그인 없이 브라우저마다 고유한 주민 키를 저장해 "내 작품"을 구분합니다. 다른 브라우저/기기에서는 기존 작품을 내릴 수 없어요.
- 배포 시 `data/`와 `uploads/` 폴더가 유지되는 서버(예: VPS, Render 디스크, Fly.io 볼륨)를 사용하세요.
